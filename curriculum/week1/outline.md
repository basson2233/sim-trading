# 教材模組 Week 1：基本面選股入門
**專案**：投資教育程式（大學 Capstone）  
**狀態**：大綱定稿（定板主題 **1**；先前「分散」大綱作廢）  
**範圍**：美股模擬組合；概念入門，少計數  
**第二期預留**：分散投資＋風險／回報

---

## 1. 學習目標
1. 說明基本面分析係用公司「經營同財務數據」判斷值唔值得買，唔係睇線圖預測短期升跌。
2. 認識三張表：損益表、資產負債表、現金流量表各自答咩問題。
3. 會用入門指標：**營收／盈利增長、本益比 (P/E)、毛利率／淨利率**（只要求理解高低大致意思）。
4. 完成本週 MC 後，按「合規標的池」買入／持有至少一隻，連續 ≥7 日，先可用 **1% 收益加成道具**。
5. 明白「跟教材選股」＝持倉同本週標的池有交集，唔係亂買都有加成。

## 2. 課文結構（網站一頁／摺疊章節）
| 章節 | 要點 | 長度 |
|------|------|------|
| 2.1 咩係基本面 | 公司賺錢能力、資產負債、現金流；同技術分析簡單對比 | ~150 字 |
| 2.2 三張表 | 損益＝賺蝕；資產負債＝有咩／欠咩；現金流＝錢點流入流出 | ~200 字 |
| 2.3 入門指標 | 營收增長、EPS／盈利增長、P/E（貴平要連同行比）、利潤率 | ~220 字 |
| 2.4 點樣用喺模擬盤 | 每週教材會公布「合規標的池」；學生讀完指標解釋後從池內選股 | ~120 字 |
| 2.5 本週任務 | 讀課文 → MC → 持倉 ∩ 標的池 ≥1 隻且持滿 7 日 → 用 1% 加成 | ~80 字 |

公開參考方向：大學投資學「權益證券／基本分析」入門單元；StockTrak／PersonalFinanceLab「What is a Stock / Research」短課＋小測模式（獎勵入虛擬賬戶）。

---

## 3. 每週 MC（5–8 題）
- 四選一；建議 7 題，及格 ≥5
- **加成雙重條件**：
  1. 本週 MC 及格；**且**
  2. 持倉 ∩ 本週合規標的池 ≠ ∅，且該合規持股連續 ≥7 日  
  → 可用 1% 收益加成道具（每週一次）
- **每週競賽**：MC 最高分額外獎勵（虛擬現金／道具，後端定）

### 題庫方向（Week 1 示例）
1. 基本面分析主要依據？（財務同經營數據）
2. 損益表主要反映？（一段期間賺蝕）
3. P/E 較高通常可能代表？（市場對增長預期較高／相對貴，視語境）
4. 只有股價圖、唔睇財報，算唔算基本面？（唔算）
5. 現金流量表最直接回答？（公司實際現金進出）
6. 想用本週 1% 加成，除咗 MC 及格仲要？（持有標的池內股票滿一週）
7. 「合規標的池」嘅意思？（教材公佈、達標先計加成嘅股票清單）

正式題目另出 `week1_mc.json`。

## 4. 合規標的池（對接加成 API）
**Week 1 示例池**（可改；建議 6–10 隻、跨 2–3 板塊，方便教「唔好單押」順便鋪第二期）：

| Ticker | 簡述（教材用） | 板塊提示 |
|--------|----------------|----------|
| AAPL | 消費電子／服務，財報透明度高，適合睇營收同利潤率 | Tech |
| MSFT | 雲同軟件訂閱，適合睇穩定盈利同現金流 | Tech |
| JNJ | 醫療消費，適合對比防禦型業務 | Health |
| PG | 日用品，穩定現金流案例 | Staples |
| JPM | 銀行，適合介紹資產負債表思維（入門） | Financials |
| XOM | 能源，適合講盈利隨商品價格波動 | Energy |
| VTI 或 SPY | （可選）闊基 ETF，若池內允許 | ETF |

**合規規則（取代舊 R1–R3）**  
| 規則 | 條件 |
|------|------|
| P1 | `持倉 ticker ∩ week.universe` 至少 1 隻 |
| P2 | 該交集持股由首次達標起連續持有 ≥7 日（賣出池內最後一隻則計時重置） |
| P3 | 本週 MC 達及格線 |

（集中度限制留第二期「分散」模組。）

## 5. 網站結合
| 角色 | 交付 |
|------|------|
| @投资专家 | 課文、MC JSON、每週 `universe[]`、規則文案 |
| @模擬交易平台程序員 | 標的池配置；MC 計分；`holdings ∩ universe`＋持滿一週檢查；加成發放；每週最高分獎勵 |
| @软件工程师 | 教材頁、MC UI、標的池展示、持倉頁「是否合規／已持幾日」、道具按鈕 |

**API 草案**  
- `GET /curriculum/week/current` → `{ weekId, lesson, universe:[], mc:[] }`  
- `POST /curriculum/week/{id}/submit` → `{ score, passed }`  
- `GET /portfolio/compliance` → `{ ok, matchedTickers[], compliantSince, heldDays }`  
- `POST /boost/apply` → 需 `mcPassed && compliance.ok && heldDays>=7`
